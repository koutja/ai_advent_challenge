# Day 02 — Контроль формата ответа

Программа на **Go** (только стандартная библиотека), которая отправляет **один и
тот же запрос** в LLM через OpenAI-совместимый API с разным уровнем управления
ответом и сравнивает результаты.

Структурирующая задача — по подсказке найти песню и вернуть
**название, исполнителя, жанр, год выхода**.

## Что демонстрирует

| Режим       | Описание                                                                                     |
|-------------|----------------------------------------------------------------------------------------------|
| `--free`    | Запрос без ограничений: никаких доп. инструкций, параметров формата/длины/стопа.             |
| `--limited` | Тот же запрос + **три уровня контроля**:                                                    |
|             | 1) явный формат (`response_format: json_object` + «ответь JSON с полями song/artist/genre/year»); |
|             | 2) ограничение длины (`max_tokens: 120` + «не более 40 слов»);                               |
|             | 3) условие завершения (`stop: ["</output>"]` + «заверши маркером </output>»).                 |
| `--run-all` | Выполняет оба режима, печатает ответы и сводную таблицу сравнения (длина, JSON, поля, стоп). |

## Структура папки

| Файл           | Назначение                                                     |
|----------------|----------------------------------------------------------------|
| `main.go`      | Клиент + флаги + сравнение                                     |
| `go.mod`       | Go-модуль                                                      |
| `Makefile`     | Цели `run-free`, `run-limited`, `run-all`, `build`             |
| `.env`         | Ключ API, базовый URL, модель (**секретный**)                  |

## Переменные окружения (`.env`)

| Переменная    | По умолчанию                 | Описание               |
|---------------|------------------------------|------------------------|
| `LLM_API_KEY` | — (обязательна)              | Ключ API               |
| `LLM_BASE_URL`| `https://api.openai.com/v1` | Базовый URL endpoint   |
| `LLM_MODEL`   | `gpt-4o-mini`                | Модель                 |

## Запуск

```bash
cd day_02

# Без ограничений
make run-free        # или go run . --free

# С ограничениями
make run-limited     # или go run . --limited

# Полное сравнение
make run-all         # или go run . --run-all

# Свой запрос аргументом (по умолчанию — предзаданный про The Beatles)
go run . --free "поищи песню: ..."
```

## Пример работы (фрагмент `--run-all`)

```
[1] БЕЗ ОГРАНИЧЕНИЙ (длина: ...)
Песня — Let It Be группы The Beatles, жанр рок, вышла в 1970 году...

[2] С ОГРАНИЧЕНИЯМИ (длина: ...)
{"song": "Let It Be", "artist": "The Beatles", "genre": "Rock", "year": "1970"}</output>

--- Таблица сравнения ---
Критерий                    | Без ограничений         | С ограничениями
...
JSON распарсен              | нет                     | да
```

> ⚠️ `.env` не коммитится. Если ваш провайдер использует другой endpoint —
> поменяйте `LLM_BASE_URL`.
