# Day 01 — Запрос к LLM через API

Минимальная программа на **Go** (только стандартная библиотека, установка зависимостей не нужна), которая отправляет запрос в LLM через OpenAI-совместимый API, получает ответ и выводит его в консоль.

## Структура папки

| Файл        | Назначение                                                           |
|-------------|----------------------------------------------------------------------|
| `main.go`   | Код: читает `.env`, принимает запрос, делает запрос к `/chat/completions`, печатает ответ |
| `go.mod`    | Описание Go-модуля (для сборки)                                       |
| `Makefile`  | Команды `make run` и `make build`                                     |
| `.env`      | Настройки: ключ API, базовый URL, модель (**секретный**)              |
| `.gitignore`| Защищает `.env` и бинарники от коммита                               |

## Как это работает

1. Программа загружает переменные из файла `.env` (функция `loadEnv`). Уже заданные переменные окружения не перезаписываются.
2. Принимает запрос пользователя: либо аргументом командной строки (`go run . "вопрос"`), либо интерактивно — ждёт ввода с клавиатуры.
3. Формирует JSON-запрос `{"model": ..., "messages": [{"role":"user","content":...}]}`.
4. Отправляет POST на `{LLM_BASE_URL}/chat/completions` с заголовком `Authorization: Bearer {LLM_API_KEY}`.
5. Разбирает JSON-ответ, берёт первый `choices[0].message.content` и печатает его в консоль.

## Переменные окружения (`.env`)

| Переменная      | Значение по умолчанию          | Описание                              |
|-----------------|--------------------------------|---------------------------------------|
| `LLM_API_KEY`   | — (обязательна)               | Ключ API                             |
| `LLM_BASE_URL`  | `https://api.openai.com/v1`   | Базовый URL endpoint                 |
| `LLM_MODEL`     | `gpt-4o-mini`                 | Модель                               |

> ⚠️ Ключ в `.env` — секрет. Файл добавлен в `.gitignore` и не должен попадать в git.
> Если ваш провайдер использует другой endpoint — поменяйте `LLM_BASE_URL` в `.env`.

## Запуск

```bash
cd day_01

# Интерактивный режим: программа спросит «Введите запрос для LLM:» и будет ждать ввод с клавиатуры.
make run
# или
go run .

# Можно сразу передать вопрос аргументом (без ожидания ввода):
go run . "Что такое градиентный спуск?"

# Сборка исполняемого файла llm_client
make build
```
