# Day 04 — Температура: влияние на ответ модели

Один и тот же запрос выполняется при трёх значениях параметра `temperature` —
`0`, `0.7`, `1.2` — и ответы сравниваются по осям **точность / креативность /
разнообразие**. В конце программа печатает выводы о том, для каких задач лучше
подходит каждая настройка.

Запрос по умолчанию: **«Главный вопрос жизни, Вселенной и всего такого»** 🎬
(можно передать свой).

## Как это работает

1. Общий клиент [`llm`](../llm/llm.go:1) читает настройки каскадом
   (окружение → локальный `.env` → корневой `.env` → дефолты) и выполняет
   `/chat/completions`.
2. Параметр `temperature` передаётся через `llm.Options.Temperature` — одно и
   то же сообщение отправляется трижды, каждый раз с другим значением.
3. Каждый ответ печатается под заголовком `=== temperature = X ===`, затем идёт
   блок `=== ВЫВОДЫ ===` с рекомендациями по каждой настройке.

## Переменные окружения (`.env`)

| Переменная      | Значение по умолчанию        | Описание                              |
|-----------------|------------------------------|---------------------------------------|
| `LLM_API_KEY`   | — (обязательна)             | Ключ API                             |
| `LLM_BASE_URL`  | `https://api.openai.com/v1` | Базовый URL endpoint                 |
| `LLM_MODEL`     | `gpt-4o-mini`               | Модель                               |

> Настройки читаются каскадом — достаточно одного корневого `/.env`. Если дню
> нужна другая модель, положите рядом маленький `day_04/.env`.

## Запуск

```bash
cd day_04

# Прогон всех температур (0, 0.7, 1.2) для запроса по умолчанию
make run            # или: go run . --run-all

# Только одно значение температуры
make run-single T=1.2        # или: go run . --single 1.2

# Свой запрос (все три температуры)
go run . "Напиши короткое стихотворение"

# Справка
go run . --help

# Сборка исполняемого файла в bin/llm_client (папка bin/ не коммитится)
make build
```

## Пример вывода

```
Запрос: "Главный вопрос жизни, Вселенной и всего такого"
Модель: gpt-4o-mini
────────────────────────────────────────────────────────────
=== temperature = 0 ===
42. Согласно «Автостопом по галактике» Дугласа Адамса...

=== temperature = 0.7 ===
Традиционный ответ — «42». Но, если задуматься, настоящий смысл в том, чтобы...

=== temperature = 1.2 ===
Слушай, а что если ответ вовсе не число, а сам путь — тусовка, кофе и хорошая
компания? Потому что 42 — это лишь шутка...

=== ВЫВОДЫ: для каких задач какая настройка ===

▶ temperature = 0
  Подходит для: точные, фактологические задачи...
  Особенности:  максимальная детерминированность и точность...
...
```

## Что сравниваем

| Настройка | Точность | Креативность | Разнообразие |
|-----------|:--------:|:------------:|:------------:|
| `temperature = 0`   | высокая  | низкая       | низкое       |
| `temperature = 0.7` | средняя  | средняя      | среднее      |
| `temperature = 1.2` | низкая   | высокая      | высокое      |
