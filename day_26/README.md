# Day 26 — Запуск локальной LLM

Локальная LLM запускается через **Ollama** и отвечает на запросы. Программа на **Go**
подключается к локальной модели через общий клиент пакета [`llm`](../llm/llm.go)
(OpenAI-совместимый эндпоинт Ollama `http://localhost:11434/v1`) и выполняет **3 запроса
разной сложности**, показывая, что модель запущена и отвечает.

Модель — `qwen2.5:0.5b` (~397 МБ): маленькая и быстрая, работает на любом Mac без GPU.

## Что проверяется

- ✅ модель запускается локально (Ollama + `qwen2.5:0.5b`);
- ✅ к ней можно обратиться через **CLI** (`ollama run`) и **HTTP API**
  (`/api/generate` — нативный, `/v1/chat/completions` — OpenAI-совместимый);
- ✅ модель отвечает на простой запрос;
- ✅ минимум 3 запроса разной сложности (через Go-клиент).

## Установка и запуск локальной LLM

```bash
# 1. Установить Ollama (macOS).
brew install ollama
# или скачать с https://ollama.com/download

# 2. Запустить сервер (держит эндпоинт http://localhost:11434).
brew services start ollama     # фоновый сервис
# либо вручную в отдельном терминале:
#   ollama serve

# 3. Скачать модель (~397 МБ).
ollama pull qwen2.5:0.5b
ollama list                   # убедиться, что модель появилась
```

## Проверка доступа (CLI + HTTP API)

```bash
# CLI — простой запрос.
ollama run qwen2.5:0.5b "Привет! Назови себя одним предложением."

# HTTP API — нативный эндпоинт Ollama (/api/generate).
curl -s http://localhost:11434/api/generate \
  -d '{"model":"qwen2.5:0.5b","prompt":"Сколько будет 7*8? Ответь только числом.","stream":false}'

# HTTP API — OpenAI-совместимый эндпоинт (/v1/chat/completions).
curl -s http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ollama" \
  -d '{"model":"qwen2.5:0.5b","messages":[{"role":"user","content":"Назови столицу Франции."}]}'
```

## Три запроса разной сложности (Go-клиент)

| Режим     | Уровень  | Что делает                                                            |
|-----------|----------|-----------------------------------------------------------------------|
| `simple`  | Простой  | Приветствие / представление модели                                    |
| `medium`  | Средний  | Генерация функции `fib(n)` на Go с объяснением и примером вызова      |
| `hard`    | Сложный  | Многошаговое рассуждение (задача на пропорции) с проверкой ответа     |
| `all`     | —        | Все три запроса подряд (по умолчанию)                                 |

## Переменные окружения (`day_26/.env`)

Настройки читаются каскадом в [`llm.New()`](../llm/llm.go): окружение → локальный
`day_26/.env` → корневой `.env` → дефолты. Локальный файл указывает на Ollama:

| Переменная     | Значение                          | Описание                          |
|----------------|-----------------------------------|-----------------------------------|
| `LLM_BASE_URL` | `http://localhost:11434/v1`       | OpenAI-совместимый эндпоинт Ollama|
| `LLM_MODEL`    | `qwen2.5:0.5b`                    | Локальная модель                  |
| `LLM_API_KEY`  | `ollama`                          | Заглушка (Ollama ключ не проверяет)|

## Запуск

```bash
cd day_26

make run            # все 3 запроса (или: go run . all)
make run-simple     # только простой
make run-medium     # только средний
make run-hard       # только сложный

make build          # собрать в bin/llm_client (без мусора в корне дня)
go vet ./...        # проверка кода
```

Результаты сохраняются в `results/<имя>.json`, детальный вывод — в `logs/<имя>.log`
(папки в `.gitignore`, в коммит не попадают).

## Структура папки

| Файл        | Назначение                                                       |
|-------------|------------------------------------------------------------------|
| `main.go`   | 3 запроса разной сложности через `llm.Client`; вывод и сохранение|
| `go.mod`    | Модуль `day_26` + `replace aichallenge/llm => ../llm`            |
| `Makefile`  | Цели `run`, `run-simple/medium/hard`, `build`                    |
| `.env`      | Локальные настройки эндпоинта Ollama (**в git не хранится**)     |
| `results/`  | JSON-результаты запросов (**в git не хранятся**)                 |
| `logs/`     | Детальные логи запросов (**в git не хранятся**)                  |
