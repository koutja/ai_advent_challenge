## Что реализовано

Агент получил три переключаемые стратегии управления контекстом (без сжатия-сводки):

| Стратегия | Файл | Принцип |
|---|---|---|
| **window** | [`window.go`](../window.go) | скользящее окно: последние N сообщений |
| **facts** | [`facts.go`](../facts.go) | блок «Факты диалога» (KV) + последние N сообщений; извлечение LLM/хьюристика |
| **branch** | [`branch.go`](../branch.go) | ветки диалога в RAM стратегии (checkpoint/branch/switch) |

Ключевые части:
- Интерфейс `ContextStrategy` + селектор ([`context.go`](../context.go)); интеграция в `Agent.Say` ([`agent.go`](../agent.go)).
- **Живой лог стратегий в вебе** — события `StrategyEvent` ([`events.go`](../events.go)) стримятся через `GET /chat/stream` (SSE) прямо в ленту чата, с иконками 🔎 делаю / ⚠ внимание / ⏳ скоро.
- **Toasts** для ошибок (чат, переключение стратегии), кнопка **«＋ Новый диалог»** с подтверждением (`POST /reset`).
- Сравнительный harness (`CompareStrategies` + прогресс) — оставлен как **отладочный инструмент** (CLI `--compare-strategies`, эндпоинты `/compare`, `/compare/stream`).

Тесты: [`window_test.go`](../window_test.go), [`facts_test.go`](../facts_test.go), [`branch_test.go`](../branch_test.go), [`context_test.go`](../context_test.go), [`events_test.go`](../events_test.go), [`compare_test.go`](../compare_test.go). `go build`, `go vet`, `go test ./...` — зелёные.

## Что показала демонстрация (реальные LLM-запросы)

Сценарий «собираем ТЗ» для мобильного приложения учёта расходов. Логи стратегий подтверждены живым стримом:

- **window**: `🔎 окно 10: история N сообщений — всё помещается в запрос`; при росте — `⏳ скоро история станет …, превысит окно — начну отбрасывать старые сообщения`. Ответ — развёрнутое ТЗ (SMART, аудитория, MVP, roadmap).
- **facts**: `🔎 факты: пока пусто, отправляю последние N сообщений` → `🔎 извлекаю ключевые факты…`; отвечает по зафиксированным фактам («стек Go + офлайн» → архитектура offline-first).
- **branch**: `🔎 ветка "main", отправляю полную историю (N сообщений) — максимум точности`.

Прозрачность сработала: до ответа видно, что делает стратегия и что произойдёт дальше.

## Замечания / известные ограничения

- LLM-провайдер (`shprotoness-ai...workers.dev`) нестабилен: периодически `timeout`;
  при недоступности сравнение/чат не проходят (в вебе это видно как toast с причиной).
- Один ход за раз: одновременные запросы к одному агенту могут пересекаться в истории.
- В 5-й реплике replay сохранён префикс «Вы: » (так лежит в базе).
