# Replay: сообщения пользователя (для повтора на других стратегиях)

> Последовательность твоих (user) сообщений, извлечённая из `agent_history.db`
> (таблица `messages`, `role='user'`, по возрастанию `id`).
> Можно прогнать этот сценарий на стратегиях `window` / `facts` / `branch`
> и сравнить, как каждая отвечает и какие логи стратегии показывает.

## Как воспроизвести

В вебе (`http://127.0.0.1:8080`):
1. Нажми «＋ Новый диалог» (подтверди сброс) — чтобы стартовать с чистого состояния.
2. Выбери стратегию (`window` / `facts` / `branch`) → «Применить».
3. Отправляй сообщения по очереди из списка выше.

Либо программно через CLI/стрим — по одному сообщению на `Say()`. Логи стратегий
(что делает стратегия и что произойдёт дальше) будут видны в чате вживую.
