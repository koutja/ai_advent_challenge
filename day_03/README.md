# Day 03 — Разные способы рассуждения

Программа на **Go** (только стандартная библиотека), которая решает **одну и ту же
аналитическую задачу** через OpenAI-совместимый API четырьмя способами и
сравнивает результаты.

Задача по умолчанию — по описанию найти песню и вернуть
**название, исполнителя, жанр, год выхода**.

## Что демонстрирует

| Флаг            | Стратегия                                                                                   |
|-----------------|----------------------------------------------------------------------------------------------|
| `--direct`      | Прямой ответ: задача отправляется как есть, без доп. инструкций.                             |
| `--step`        | Добавляем «Решай пошагово» — модель объясняет каждый шаг.                                    |
| `--prompt-gen`  | Модель сначала составляет промпт для решения задачи, затем этим промптом «решает» (2 вызова).|
| `--panel`       | Группа экспертов: аналитик, инженер, критик. Каждый — system-сообщение; получаем ответ каждого. |
| `--run-all`     | Все четыре стратегии последовательно + таблица сравнения и вердикт.                          |

## Структура папки

| Файл           | Назначение                                                     |
|----------------|----------------------------------------------------------------|
| `main.go`      | Клиент + 4 стратегии + сравнение                               |
| `go.mod`       | Go-модуль                                                      |
| `Makefile`     | Цели `run-direct`, `run-step`, `run-prompt-gen`, `run-panel`, `run-all`, `build` |
| `.env`         | Ключ API, базовый URL, модель (**секретный**)                  |
| `demo/demo.sh` | Демонстрация через demo-magic (видео не записываем)            |

## Переменные окружения (`.env`)

| Переменная    | По умолчанию                 | Описание               |
|---------------|------------------------------|------------------------|
| `LLM_API_KEY` | — (обязательна)              | Ключ API               |
| `LLM_BASE_URL`| `https://api.openai.com/v1` | Базовый URL endpoint   |
| `LLM_MODEL`   | `gpt-4o-mini`                | Модель                 |

## Запуск

```bash
cd day_03

make run-direct       # или go run . --direct
make run-step         # или go run . --step
make run-prompt-gen   # или go run . --prompt-gen
make run-panel        # или go run . --panel
make run-all          # или go run . --run-all

# Своя задача аргументом
go run . --step "моя логическая задача: ..."
```

## Пример работы (фрагмент `--run-all`)

```
=== direct ===
Это песня Let It Be группы The Beatles, рок-баллада 1970 года...

--- Таблица сравнения ---
Стратегия   | song        | artist     | genre | year
direct      | 'Let It Be' | 'The Beatles'| 'Rock' | '1970'
step        | ...
...
Вердикт: наиболее точный результат дала стратегия "panel" (полнота ответа 5/5).
```

> ⚠️ `.env` не коммитится. Если ваш провайдер использует другой endpoint —
> поменяйте `LLM_BASE_URL`.
