# day_05 — Версии моделей

Сравнение одного и того же запроса на **слабой**, **средней** и **сильной**
модели: замеряем время ответа, количество токенов и стоимость. Качество
оцениваем по рейтингу Elo из каталога [`../llm/models.json`](../llm/models.json)
и по текстам ответов.

## Что делает

1. Читает `config.json` — какие модели сопоставлены тирам (`weak`/`medium`/`strong`),
   какой endpoint и ключ использовать, цены за 1М токенов.
2. Для каждого выбранного тира отправляет запрос через общий пакет `llm`
   (метод `ChatResult`, возвращает текст + usage + время).
3. Считает стоимость: `(prompt * price_in + completion * price_out) / 1e6`.
4. Собирает markdown-отчёт: таблица сравнения, полные ответы, короткий вывод.
5. Пишет построчный лог в `logs/day05.log` и отчёт в `results/day05_report.md`.

**Устойчивость:** если API не вернуло `usage`, цену или ответ — в таблице
ставится «–» («не удалось получить»), прогон продолжается и не падает.

## Переменные окружения

- `LLM_API_KEY` — ключ API.
- `LLM_BASE_URL` — базовый URL OpenAI-совместимого endpoint
  (например `https://shprotoness-ai.jq9gfk.workers.dev/v1`).

В `config.json` поля `env_key` и `base_url` — это **имена env-переменных**, а не
сами значения (значения лежат в `.env` и читаются каскадом через `llm`).
У конкретного тира можно переопределить их через `tier.env_key` / `tier.base_url`
(тоже имя переменной). Если `LLM_BASE_URL` не задана — используется дефолтный
URL пакета `llm`.

## Запуск

```bash
# быстрая отладка на дешёвой модели (weak = deepseek-v4-flash)
make run-cheap          # go run . --cheap

# одна конкретная модель
go run . --tier weak
go run . --tier medium
go run . --tier strong

# все настроенные тиры
make run-all            # go run . --run-all

# свой запрос
go run . --run-all "Придумай заголовок статьи"
```

Сборка бинарника: `make build` → `bin/llm_client` (папка `bin/` в `.gitignore`).

## Как настроить тиры под себя

В `config.json` у каждого тира указан канонический `id` из
[`../llm/models.json`](../llm/models.json) (этот `id` уходит в API как имя
модели): `weak=deepseek-v4-flash`, `medium=deepseek-v4-pro`,
`strong=gpt-5.6-sol`. При необходимости меняйте `id`, добавляйте свои
`base_url`/`env_key` и цены за 1М токенов в `prices_usd_per_mtok`. Если у модели
нет цены или API не вернул `usage` — в таблице будет «–».

## Пример вывода

Таблица сравнения, полные ответы по каждому тиру и блок «Вывод» с краткими
выводами: кто быстрее, кто дороже, у кого выше Elo и больший расход токенов.
